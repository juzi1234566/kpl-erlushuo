# KPL 二路说 · erlushuo.xyz

> 把一场 KPL 比赛,浓缩成 **3 分钟能看完的赛评**。

🔗 在线访问:**[erlushuo.xyz](https://erlushuo.xyz)**

AI 自动聚合 B 站二路解说的公开观点,结合官方赛果数据,为每场比赛生成四个栏目:

| 栏目 | 内容 |
|------|------|
| BP 点评 | 赛前禁选的战术意图 |
| 选手评价 | 关键表现者的解说评价 |
| 赛后复盘 | 胜负转折点分析 |
| 金句时刻 | 解说精彩原声,回链原视频 |

已覆盖 **2026 KPL 夏季赛全部赛程**。

---

## 产品原则

这是一个粉丝自发的**非官方**项目,与腾讯、KPL 赛事、各俱乐部及各解说均无隶属关系。在写第一行代码之前,先定下了三条约束:

1. **AI 生成内容 100% 明确标识**,不伪装成真实用户;
2. **观点归属原作者**——引用注明解说来源并回链原视频;
3. **侵权响应机制**——提供投诉入口,目标 24 小时内处理。

依据与取舍过程见 [`docs/决策记录.md`](docs/决策记录.md)(为什么网站先行、为什么放弃某些数据源、合规红线怎么划)。

## 项目结构

```
web/        Next.js 前端(部署于 erlushuo.xyz)
pipeline/   数据管线:官方赛果接口封装、观点抽取、写入 Supabase
supabase/   数据库迁移
docs/       PRD、迭代决策记录、合规声明
```

## 项目演进

项目最初的方向是 KPL 玩梗社区「梗局」(见 [`docs/PRD.md`](docs/PRD.md)),后转向信息密度更高、冷启动更轻的「二路说」赛评聚合。转向的判断:玩梗社区依赖用户生态(UGC 冷启动难),而赛评聚合**上线第一天就有完整内容**,先靠内容站住,再谈社区。
