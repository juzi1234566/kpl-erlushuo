4. **本地 web**：梗百科 `fromDb`  
5. **Vercel 部署** Root=`web` + 公开 URL  
6. **Phase 1**：Auth → 发帖评论点亮 → bot 发帖链路 → 选手页 → 管理后台  
7. **内容**：梗词条 ≥50；DeepSeek 质量人工抽检 10 条  
8. **语录 / 云主机**：按计划并行，勿挡 8/17 主路径  

**不要：**

- 擅自改品牌为含「KPL」商标的主域名  
- 做假用户暖场  
- 把 `service_role` 提交进仓库或暴露给浏览器  
- 用 Redis 重写队列除非有明确规模需求
